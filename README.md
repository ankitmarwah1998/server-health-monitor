# Server Health Monitor 🖥️

A simple Python CLI tool to monitor CPU, RAM, and Disk usage with logging and alerts.

## 🚀 Features
- Real-time CPU, RAM, Disk monitoring
- Alert on high CPU usage (> 80%)
- Logs stored in `log.txt`

## 📦 Requirements
- Python 3.x
- psutil

## 🔧 Setup

```bash
pip install -r requirements.txt
python monitor.py
